# 二手车价格预测 - 特征工程总结

## 一、原始数据概况

### 1.1 数据来源

| 数据集 | 文件名 | 样本数 | 说明 |
|--------|--------|--------|------|
| 训练集 | `used_car_train_20200313.csv` | 150,000 | 含 price 标签 |
| 测试集 | `used_car_testB_20200421.csv` | 50,000 | 无 price，需预测 |

### 1.2 原始字段（31列）

| 字段名 | 类型 | 唯一值 | 缺失数 | 说明 |
|--------|------|--------|--------|------|
| SaleID | int | 150,000 | 0 | 交易ID，唯一标识 |
| name | int | 99,662 | 0 | 汽车编码 |

| creatDate | int | 96 | 0 | 上架日期（20160404格式） |
| model | float | 248 | 1 | 车型编码 |
| brand | int | 40 | 0 | 品牌编码 |
| bodyType | float | 8 | 4,506 | 车身类型 |
| fuelType | float | 7 | 8,680 | 燃油类型 |
| gearbox | float | 2 | 5,981 | 变速箱类型 |
| power | int | 566 | 0 | 发动机功率 |
| kilometer | float | 13 | 0 | 行驶里程（万km） |
| notRepairedDamage | str | 3 | 0 | 是否有未修复损伤（-/0.0/1.0） |

| seller | int | 2 | 0 | 销售方（几乎全是0） |

### 1.3 数据特点

- **price**：范围 11~99,999，均值 5,923，中位数 3,250，偏态严重（skew=3.35）
- **power**：存在异常值（>600的143条，0值的12,829条）
- **notRepairedDamage**：存在特殊值 "-"（24,324条）
- **regionCode**：高基数特征（7,905种），训练集和测试集不完全一致
- **日期**：regDate（1991~2015）、creatDate（2015.6~2016.4）

## 二、特征工程方案

### 2.1 总体思路

```
原始特征 → 预处理 → 日期特征工程 → 数值特征派生 → 类别交互特征 → 特征选择
   ↓            ↓            ↓               ↓               ↓              ↓
  清洗数据    缺失值处理   时间信息提取    业务逻辑派生    组合特征       筛选有效特征
```

### 2.2 Power 特征工程

**问题**：原始 power 存在 12,829 条 0 值、143 条异常值（>600），范围极广（0~19,312）

**处理方案**：

| 衍生特征 | 计算公式 | 目的 |
|---------|---------|------|
| `power_clipped` | `power.clip(0, 600)` | 裁剪异常值，限制在合理范围 |
| `power_log` | `log1p(power_clipped)` | 对数变换，压缩长尾分布 |
| `power_bin` | 分箱 `[0,30,60,90,120,150,200,300]` | 转为类别特征，捕捉非线性关系 |
| `is_high_power` | `power_clipped >= 150` | 二值化标识高功率车辆 |
| `power_per_year` | `power_clipped / (car_age + 0.5)` | 单位车龄的功率，反映车辆"动力密度" |
| `power_km_ratio` | `power_clipped / (kilometer + 0.5)` | 功率与里程比，反映车辆使用强度 |

### 2.3 日期特征工程

**问题**：原始 regDate 和 creatDate 为整数格式（如 20040402），信息量未充分利用

**处理方案**：

| 原始字段 | 衍生特征 | 说明 |
|---------|---------|------|
| regDate | `reg_year`, `reg_month`, `reg_day` | 拆分年、月、日 |
| creatDate | `create_year`, `create_month`, `create_day` | 拆分年、月、日 |
| - | `reg_quarter`, `create_quarter` | 季度（1-4），捕捉季节性 |
| - | `reg_decade` | 年代（如2000s, 2010s），反映车龄层级 |
| - | `reg_is_early_year`, `reg_is_late_year` | 是否年初/年末注册 |

**时间差特征**：

| 特征 | 计算公式 | 说明 |
|------|---------|------|
| `car_age` | `(create_date - reg_date).days / 365.25` | 上架时的车龄（年） |
| `car_age_months` | `car_age * 12` | 车龄（月），更精细 |
| `car_age_now` | `(ref_date - reg_date).days / 365.25` | 截至参考日期的车龄 |
| `listing_days` | `(ref_date - create_date).days` | 上架时长（天） |

### 2.4 车辆状态特征

基于车龄派生的业务特征：

| 特征 | 条件 | 说明 |
|------|------|------|
| `is_new_car` | `car_age <= 1` | 是否新车（≤1年） |
| `is_almost_new` | `1 < car_age <= 3` | 是否准新车（1-3年） |
| `is_old_car` | `car_age > 8` | 是否老车（>8年） |
| `car_age_sq` | `car_age²` | 车龄平方，捕捉非线性折旧 |

### 2.5 使用强度特征

| 特征 | 计算公式 | 说明 |
|------|---------|------|
| `usage_intensity` | `kilometer / (car_age + 0.5)` | 年均行驶里程，反映使用强度 |
| `kilometer_bin` | 分箱 `[0,3,6,9,12,15]` | 里程分段（万km） |

### 2.6 交互类别特征

**核心思路**：将多个类别特征组合，创造有业务含义的复合类别

| 特征 | 组合方式 | 业务含义 |
|------|---------|---------|
| `brand_model` | `brand + "_" + model` | 品牌+车型组合（最重要的交互） |
| `brand_bodyType` | `brand + "_" + bodyType` | 品牌×车身类型 |
| `fuel_gear` | `fuelType + "_" + gearbox` | 燃油类型×变速箱 |
| `brand_fuel` | `brand + "_" + fuelType` | 品牌×燃油类型 |
| `brand_age` | `brand + "_" + age_group` | 品牌×车龄段 |
| `body_fuel` | `bodyType + "_" + fuelType` | 车身类型×燃油类型 |
| `region_province` | `regionCode // 100` | 省份编码（地区简化） |

### 2.7 特征汇总

**增强前（35个特征）**：

```
数值特征(27): power, kilometer, v_0~v_14, reg_year, reg_month, reg_day,
              create_year, create_month, create_day, car_age, car_age_now,
              listing_days, is_new_car, notRepairedDamage_encoded

类别特征(8): brand, bodyType, fuelType, gearbox, model, regionCode,
             notRepairedDamage, seller
```

**增强后（60个特征）**：

```

              kilometer, usage_intensity, car_age, car_age_months, car_age_now,
              car_age_sq, listing_days, is_new_car, is_almost_new, is_old_car,
              is_high_power, v_0~v_14, reg_year, reg_month, reg_day,
              create_year, create_month, create_day

类别特征(19): brand, bodyType, fuelType, gearbox, model, regionCode,
              power_bin, kilometer_bin, age_group,
```

## 三、模型编码策略

### 3.1 CatBoost 原生编码

**优势**：CatBoost 对类别特征使用 **有序目标编码（Ordered Target Encoding）**，自动防止数据泄露。

**使用方法**：
```python
# 将类别特征转为字符串
for col in cat_features:
    df[col] = df[col].astype(str)

# 在 Pool 中指定类别特征
train_pool = Pool(X_train, y_train, cat_features=cat_features)
```

### 3.2 缺失值处理

| 特征类型 | 处理方式 |
|---------|---------|
| 数值特征 | 训练集中位数填充 |
| 类别特征 | CatBoost 自动处理 |
| notRepairedDamage | 特殊值 "-" → -1，"0.0" → 0，"1.0" → 1 |

### 3.3 高基数特征处理

| 特征 | 基数 | 处理方式 |
|------|------|---------|
| regionCode | 7,905 | CatBoost 自动有序目标编码 + 省份简化编码 |
| brand_model | ~9,920 | CatBoost 自动有序目标编码 |
| model | 248 | CatBoost 自动有序目标编码 |

## 八、后续优化方向

### 8.1 特征层面

| 方向 | 具体思路 | 预期收益 |
|------|---------|---------|
| 统计特征 | 按 brand/model/region 统计 price 的均值/中位数/标准差 | 中 |
| 频率编码 | 高基数特征的频率编码 | 低 |
| 更细粒度分箱 | power 用更精细的分箱，kilometer 用具体数值段 | 低 |
| 特征选择 | 基于重要性剔除 Top 10 之后的低重要特征 | 低（可能提升泛化） |

### 8.2 模型层面

| 方向 | 具体思路 | 预期收益 |
|------|---------|---------|
| Stacking | 融合 CatBoost + LightGBM + XGBoost | 中-高 |
| Blending | 加权平均多个模型的预测结果 | 中 |
| 调参优化 | 网格搜索/贝叶斯优化最优参数 | 低-中 |
| 目标变换 | 对 price 取 log 变换后训练，再反变换 | 低（可能改善高价格区间） |

### 8.3 数据层面

| 方向 | 具体思路 | 预期收益 |
|------|---------|---------|
| 异常值处理 | 对 price 高价格样本做特殊处理 | 低 |
| 分组建模 | 按 price 区间分组训练不同模型 | 中 |
| 数据增强 | 对低价格区间进行过采样 | 低 |
